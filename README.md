# opal

A graphical programming editor built on [agate](https://github.com/adam3141/agate) and [flint](https://github.com/adam3141/flint), part of the [silica](https://github.com/adam3141/silica) workspace.

**Status: not started.** Work on opal begins once agate's UI model is settled. Its design will be based on agate's API documentation.
